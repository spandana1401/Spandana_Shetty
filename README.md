# DevOps Portfolio Website

## Overview

This repository contains my personal portfolio website developed using HTML, CSS, and JavaScript and hosted on GitHub Pages. The portfolio showcases my professional experience, technical skills, certifications, projects, education, and contact information in a structured and interactive format.

The objective of this project is to provide a centralized platform to demonstrate my experience in AWS Cloud, Kubernetes, CI/CD, Infrastructure Automation, Monitoring, Linux Administration, and AI-powered cloud solutions.

## Deployment

The website is deployed using GitHub Pages.

### Steps Followed

1. Created a GitHub repository.
2. Initialized Git locally.
3. Added project files to the repository.
4. Committed changes using Git.
5. Pushed code to GitHub.
6. Enabled GitHub Pages deployment from the main branch.
